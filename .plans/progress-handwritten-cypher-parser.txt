TASK-018 (semantic analysis) - DONE
  * cypher/analyze: typed Error{Class, Code, Pos, Msg}; Check(); Describe().
    Lexer/parser errors carry TCK codes (syntax.SyntaxError.Code / ErrorCode()).
    cypher.Parse = syntax.Parse -> analyze.Check -> lowering.
  * Results: all 586 compile-time-error cases in the TCK produce the exact expected
    class and code; 0 of 4,176 valid queries are wrongly rejected; strict harness
    pass rate 816/2,631 (31.0%) -> 911/2,631 (34.6%). FuzzCheck: 23M executions,
    no panics.
  * Design notes (also in AGENTS.md): zero false positives is a hard requirement
    (TestTCK_ValidScenariosPass); path variables are bound after their elements;
    the aggregation grouping rule is leaf-by-leaf; NoExpressionAlias is reported
    after the other projection checks; type inference only reports proven
    mismatches (unknown stays unknown).
  * Not covered: procedure signatures/arguments (task-026) and every runtime error
    expectation (those still accept any error in the harness).
